# Working with AI agents: Coding Example 3

This example uses the [English quotes dataset](https://huggingface.co/datasets/Abirate/english_quotes) by Abir Eltaief.

1. Download the dataset using the code snipped provided in `src`.
2. Parse the dataset.
3. List all available unique tags and write them to a textfile.
4. Create a filter by tag.
5. Print the first three quotes by the tag `humor`.
